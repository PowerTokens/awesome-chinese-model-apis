# Security Policy

This repository is a curated list, so it contains no runnable service. If you find a security problem in a listed resource, please report it to that project directly.

If you notice something in this repository that could put readers at risk (for example a link that now points to a malicious site, or an example that exposes an API key), please email **service@powertokens.ai** instead of opening a public issue. We aim to reply within a few business days.

Never paste real API keys into issues, pull requests or discussions.
